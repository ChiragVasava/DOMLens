STAGE 1: POPUP INITIATION Beginner Concept Guide

1. User Clicks the DOMLens Toolbar Icon

When you click the extension's icon in Chrome's top toolbar, Chrome opens the popup/popup.html window. Think of this popup as the extension's remote control.

💡 The Core Concept: Chrome Extension Architecture

Chrome extensions are deliberately divided into separate security sandboxes. The Popup cannot directly see or touch the HTML elements of the website (like YouTube) for security reasons. It must ask the Background Service Worker to coordinate.

🎯 Real-world analogy: The Popup is like an elevator button. Pressing it doesn't move the elevator car directly; it sends an electrical signal to the elevator motor room.

Files & Functions in Action:

// popup/popup.js
toggleBtn.addEventListener('click', () => {
  chrome.runtime.sendMessage({ action: 'TOGGLE_INSPECT' });
});
Data Sent over Message Bus:

🧠 Beginner's Encyclopedia: 6 Core Concepts Used in DOMLens
🌐
1. The 3 "Worlds" of Chrome Extensions
A Chrome extension is not a standard website. It is split into 3 distinct parts that run in separate processes:
  • Popup (UI): The small window that opens when you click the toolbar icon. It dies as soon as you click away.
  • Service Worker (Headless): A background script (background.js) that stays dormant until an event wakes it up.
  • Content Script (In-Page): JavaScript (inspector.js) injected directly into the active tab's DOM tree.
🎯 Analogy: Think of a restaurant. Popup is the customer placing an order; Background Worker is the head chef dispatching tickets; Content Script is the waiter bringing food directly to your table.
📡
2. Inter-Process Communication (IPC)
Because the Popup and Webpage cannot talk directly, Chrome provides an encrypted message highway:
  • chrome.runtime.sendMessage(): Sends a message from Popup to Background.
  • chrome.tabs.sendMessage(tabId, message): Sends a message from Background to a specific browser tab.
  • chrome.runtime.onMessage.addListener(): Catches incoming messages and executes logic.
🎯 Analogy: Like a postal service. You don't walk across the country to give someone a letter; you put it in the mailbox (Chrome Message Bus) with an address (tabId), and Chrome delivers it.
🛡️
3. Encapsulated Shadow DOM
Normally, if an extension injects an <h1> into a webpage, the webpage's CSS (like red color or huge font) will ruin the extension's design.

Shadow DOM allows DOMLens to attach a hidden, soundproof root: element.attachShadow({ mode: 'open' }). Inside this bubble, external CSS cannot penetrate, and DOMLens's styles cannot leak into the webpage!
🎯 Analogy: A soundproof VIP glass booth inside a loud concert. You can see everything outside, but the loud music outside doesn't disrupt what's happening inside.
⚡
4. Event Capture Phase (`true`)
When you click a link on a website, the event goes down from window to the element (Capture Phase), and then bubbles back up (Bubbling Phase).

Websites like YouTube listen on the bubbling phase to open videos. If DOMLens waited for bubbling, the video would open! By using window.addEventListener('click', handler, true), DOMLens catches the click first, halts navigation with e.preventDefault(), and inspects the element safely!
🎯 Analogy: A security guard stationed at the front gate (Capture Phase) checking your ticket before you can enter the stadium, rather than checking you inside the seat (Bubbling Phase).
🏛️
5. Single Source of Truth State
When an element is clicked, DOMLens's ComponentState stores two things:
  • `original`: An immutable frozen copy of the element's original HTML and CSS.
  • `current`: The live working copy (current.html and current.css).
Every tab (Live Preview, Code, Edit) reads from current. If an AI edit goes wrong, clicking "Reset" restores original with 100% exact fidelity!
🎯 Analogy: Saving a master backup copy of your final year dissertation before you start experimenting with edits.
🤖
6. Cascading AI Fallback (503 Circuit Breaker)
Google Gemini free tier often suffers from capacity drops returning HTTP 503 ("Model Overloaded"). Most apps crash or throw an error. DOMLens implements an intelligent cascade:

It retries gemini-3.8-flash with backoff; if still down, it automatically cascades: 3.8 → 3.7 → 3.6 → 3.5 → 3.5-lite without user intervention.
🎯 Analogy: Like having a primary doctor. If Dr. 3.8 is busy in emergency surgery, you are automatically attended to by Dr. 3.7 or Dr. 3.6 instead of being told to go home!
